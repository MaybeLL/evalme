## 复现

在独立的 PostgreSQL 18 测试服务中运行，必须具备创建/删除测试数据库和测试角色权限。`EVALME_TEST_PG_CONFIG` 与 `EVALME_TEST_PG_ADMIN_CONFIG` 指向原业务测试专用连接；不得指向共享生产库。

```sh
EVALME_SETUP_PG_PORT=<隔离测试端口> \
EVALME_SETUP_PG_CONTAINER=<对应测试容器> \
EVALME_TEST_PG_CONFIG=<测试应用配置> \
EVALME_TEST_PG_ADMIN_CONFIG=<测试管理配置> \
node --test mvp/tests/*.test.mjs
```

用 Node 22.16.0 和 Node 24.21.0 分别运行。本轮临时数据库、角色与容器已清理，既有测试容器恢复停止状态。后续生产迁移、发布与公司电脑跨机验收应单独安排和记录。
