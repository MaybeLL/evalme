## 测试方法

`tests/installer.test.mjs` 使用隔离 HOME，调用实际 install.sh、npm pack、npm ci、已安装包装脚本。测试仅复用下载缓存，不复用真实用户配置；覆盖安装、初始化、升级、冲突、卸载、重装及配置清理。安装器依赖 curl/tar/npm，联网或缓存可用是前提。

`tests/tty.test.mjs` 用 Python PTY 驱动真实 CLI，实际输入密码，检查终端输出中没有密码、配置不含明文密码，独立密码文件可用于后续读取。

PG 验证仅使用已有独立测试容器及测试账号，不指向正式学习库。Node 22.16.0 来自 nodejs.org 官方归档，并校验官方 SHA256。最终在 macOS arm64 本机执行结果：

| 运行时 | SQLite + 独立真实 PostgreSQL | 安装生命周期 |
|---|---|---|
| Node 22.16.0 | 66 tests / 66 pass / 0 fail / 0 skipped | 包含在同一套测试内，通过 |
| Node 24.21.0 | 66 tests / 66 pass / 0 fail / 0 skipped | 包含在同一套测试内，通过 |

安装升级测试还验证了新包 Skill 模板确实被安装、修改过的 Skill 导致升级停止且旧入口保留、生成凭据可随 purge-config 清理。测试完独立 PG 服务已停止，卷保留；没有修改正式学习库。上述不代表整机重启、Linux CI、公司电脑新版安装或宿主发现已通过。

## 公司电脑验收（需发布新版后执行）

1. 保留原 Node 22.16；确认旧版已卸载、Tailscale 可到达服务端。
2. 执行主 README 的两条命令：安装入口、init。无需源码操作、手写 JSON、chmod、切换 Node 或复制 Skill。
3. 选择 PG，输入自己的连接信息和应用密码；密码不在终端回显、聊天或命令历史中。
4. doctor 返回 ready=true；新 Pi 会话发现 evalme-mvp，通过共享 Skill 查询已有任务。Codex 另行检查，不以 Pi 成功替代。
5. 保存一条真实任务/练习/评价，Mac Studio 查回；反向创建/读取也由真实两台机器完成。新版尚未执行此项，旧版跨机结果不自动继承为新版安装验收。
6. 升级后仍能查回历史；默认卸载后 Node 22、其他 Skill、数据保留；重新安装后配置可复用。
7. 如需清理本机连接，使用 uninstall --purge-config，确认不会删除远程数据库或 SQLite 文件。

## 明确限制

- 安装器不会自动安装 Node 或改系统默认 Node；缺少兼容运行时会提前报错并给出指引。
- 若 ~/.local/bin 不在 PATH，使用安装器输出的绝对路径；不会偷偷修改 shell 配置。
- 服务端部署、Tailscale 权限和 schema 初始化是远程连接的前置条件；init 不扩大账号权限。
- 仅操作有所有权标记的 CLI/Skill，旧手工安装需先按原方式卸载。未知文件不盲目删除。
- 默认卸载保留配置与密码；purge-config 仅删除默认配置及其当前引用的自动生成密码文件，历史密码/外部文件/Skill 备份保留。
- 不支持任意大版本 Node；Windows 原生路径/权限尚未适配验证。
- main 是目前的远程分发源；公开发布前须检查差异并获得发布授权。没有发布到 npm。
